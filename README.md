# Tiny Archipelago: privacy policy

The public privacy policy of **Tiny Archipelago**, a cozy low-poly island game for children and families, by NeonexaLabs.

Read it at https://neonexalabs.github.io/tiny-archipelago-privacy/

Questions about privacy: neonexalabs@gmail.com

## About these files

The page is built from the game's own source files, so a change to the policy is made there and the page is built again: edits made
here by hand are overwritten the next time. GitHub Pages serves it from the `main` branch. It loads nothing from other sites (no web
fonts, scripts, analytics or trackers) and has no script of its own.

The font is Nunito, used under the SIL Open Font License 1.1 (`assets/fonts/OFL.txt`).
